# Fortnite PE

**Fortnite PE (Performance Edition)** is a stylized 3D battle-royale-style browser game built with HTML, JavaScript, and Three.js.

## Visual upgrade
The game is no longer presented as a low-poly prototype. The current build uses smoother, higher-segment character, weapon, tree, rock, and terrain geometry with more polished presentation.

## Features
- Smooth 3D third-person combat and player customization
- Procedural island terrain with towns, houses, trees, rocks, roofs, and loot chests
- Weapons with rarity tiers, ammo, reloads, spread, recoil, and hit feedback
- Enemy bots with looting, combat, movement, and storm awareness
- Storm-circle gameplay and minimap
- Building system: F1 Wall, F2 Ramp, F3 Floor
- Polished HUD, inventory, pause/settings screens, and credits
- Local settings persistence
- Credits for **JacobProjects**

## Controls
- WASD: move
- Mouse: look
- Left click: shoot / place selected building piece
- Right click: aim
- Space: jump / leave the battle bus
- Shift: sprint / descend while gliding
- R: reload
- 1–5: select weapon
- E: open chest / pick up loot
- Z / X / C: Bandage / Medkit / Shield
- F1 / F2 / F3: Wall / Ramp / Floor
- Esc: pause

## Running locally
Open **Fortnite PE.html** in a modern browser, or serve the repository with a small local HTTP server. The game loads Three.js from a CDN, so an internet connection may be required at launch.
